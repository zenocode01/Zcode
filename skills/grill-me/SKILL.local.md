# grill-me（本地精简版）

## 何时使用

- 用户要求拷问某计划/决定时

## 工作流程

1. 画设计树：决定 → 下游决定
2. 只问"前沿"：前置已定的决定
3. 每轮问全部前沿，固定格式：
   - ❓ Q#: 问题
   - ➡️ 推荐: 你的答案
4. 等用户答完再进下一轮
5. 事实自己查（文件/工具），决定逐个问用户
6. 前沿为空且用户确认 → 才行动

## 输出格式

- 树: <决定> → <下游>
- 共识: <确认的决定清单>

## 兜底

- 查不到事实 → 明说"未查到"，不让用户代劳
- 用户没答 → 不猜，等回答
