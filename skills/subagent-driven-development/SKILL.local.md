# subagent-driven-development（本地精简版）

## 何时使用

- 有实现计划、任务相互独立、宿主有子代理工具

## 工作流程

1. 建 ledger 到 .memory/sdd-ledger.md，检查既有进度续跑
2. 记录 BASE = git rev-parse HEAD
3. 每任务派新子代理：文件传 brief + 相关接口 + 报告路径，不粘历史
4. 子代理实现 + 测试 + 报告（状态/提交/测试摘要）
5. 派审查者查 diff：规格符合？质量分级（Critical/Important/Minor）
6. 有问题修复，最多 3 轮（第 1-2 轮原实现者，第 3 轮换模型）
7. 全部完成 → 全分支审查一次，修完合并清理

## 硬规则

- 子代理独立上下文，不继承会话历史
- 控制器不亲自修代码
- 审查不可跳过
- 超修复上限 → 停止，向用户报告，不静默丢弃
- 不在 main 直接实现（先开分支）

## 输出格式

- ledger: .memory/sdd-ledger.md
- 报告: 状态 + 提交 + 测试摘要

## 兜底

- 无子代理工具 → 单代理逐任务执行
- 本地模型做控制器 → 修复轮数 3，审查交给宿主更强模型
