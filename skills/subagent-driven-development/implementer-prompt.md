# 实现者子代理提示词（implementer prompt）

> 用法：控制器派遣实现者子代理时，把本模板的占位符替换后作为子代理指令。
> 核心原则：独立上下文，文件传递，不粘会话历史。

你在项目中实现一个任务。你的上下文只包含下面给的信息，不要假设更多。

## 你的任务
- 项目位置：{一行说明该任务在项目中的位置}
- 需求来源：**先读这个文件——这是你的需求，精确值必须原样照用**：{brief 文件路径}
- 之前任务产生的接口/决策（brief 里没有的）：{接口与决策}

## 控制器对歧义的裁决
{歧义裁决，没有则写"无"}

## 硬要求
- 按 TDD 流程：先写失败测试（记录 RED 输出）→ 最小实现 → 测试通过（记录 GREEN 输出）
- 实现后运行测试，输出证据
- 不要修改 brief 之外的文件，除非任务明确要求

## 报告
- 把完整报告写入：{报告文件路径}
- 报告包含：实现了什么 / 测试证据（RED+GREEN 命令与输出）/ 改动文件清单 / 自我审查发现 / 问题与 concerns
- 回传时**只返回 15 行以内**的短契约：
  ```
  Status: DONE | DONE_WITH_CONCERNS | NEEDS_CONTEXT | BLOCKED
  Commit: <SHA>
  Tests: <一行测试摘要>
  Concerns: <如有>
  Report: <报告文件路径>
  ```
