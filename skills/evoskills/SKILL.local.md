# evoskills（本地精简版）

## 何时使用

- 会话结束时，或技能反复失败时

## 工作流程

1. 记录使用：zcode skill log <技能> 成功|失败|改进 --lesson "<教训>"
2. 审计：zcode skill audit <技能>
3. 成功率 <70% 或改进建议 ≥2 条 → 改技能
4. 读教训和建议，逐条改 SKILL.local.md（显式兜底/简化步骤）
5. 用改后技能重跑一次近期失败任务验证
6. 有效 → 勾选 improvements.md 发布；无效 → 回滚

## 硬规则

- 同类失败 ≥2 次才改，不因个案膨胀
- 本地版验证后同步标准版
- 发布后重新 audit 确认回升

## 输出格式

- 记录: .memory/experience.log
- 评估: audit 报告

## 兜底

- 样本不足 → 不迭代
- 改进无效 → 回滚，记录教训
