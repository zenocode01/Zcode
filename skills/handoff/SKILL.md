# handoff — 会话接力（标准版）

## 何时使用

- **会话开始时**：读取接力快照，恢复上下文（目标、进行中事项、决策、验证结果）
- **会话结束时 / 关键里程碑**：保存接力快照，供未来会话恢复

## 工作流程

1. **会话开始**：执行 `zcode handoff load`，读取快照。
   - 有快照 → 恢复：当前目标、进行中事项、决策记录、验证结果、下一步建议
   - 无快照 → 正常开始，无需接力
2. **会话进行中**：关键决策、验证结果出现时，记录在案（决策含原因，验证含结果）。
3. **会话结束 / 交接点**：执行 `zcode handoff save`，填写六要素：
   - `--goal` 当前目标（一句话）
   - `--achieved` 已完成事项
   - `--in-progress` 进行中事项（明确下一步）
   - `--decisions` 决策记录（含原因，格式：决策（原因：...））
   - `--validation` 验证结果（如测试通过/检索命中）
   - `--next` 下一步建议（可执行的具体动作）

## 输出格式

- 快照文件：`<project>/.memory/handoff.md`（或 `--global` 存 `~/.zcode/handoff.md`）
- 六要素齐全：目标 / 已完成 / 进行中 / 决策 / 验证 / 下一步

## 兜底

- 快照缺失 → 明说"无接力快照"，不臆造历史
- 保存失败（无写权限）→ 报告路径，改用全局存储
- 快照内容与当前事实矛盾 → 以当前会话实际状态为准，更新快照
