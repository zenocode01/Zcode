# diagnose（本地精简版）

## 何时使用

- 用户报告代码坏掉/变慢/报错时

## 工作流程

1. 建最小复现：失败测试或单条命令，能稳定红
2. 复现用户描述的确切症状，削减输入直到每个元素都必要
3. 列 3-5 个可证伪假设，先展示给用户再测
4. 一次只改一个变量；日志带 [DEBUG-xxxx] 前缀
5. 修复前先写回归测试，再修
6. 清理临时代码，复盘"什么能防止此 bug"

## 输出格式

- 复现: <命令>
- 根因: <假设+证据>
- 修复: <文件>
- 测试: <路径>
- 复盘: <结论>

## 兜底

- 建不了复现 → 停止，向用户要环境/权限，列出已试方式
- 测试全红 → 报告卡点，不瞎猜根因
