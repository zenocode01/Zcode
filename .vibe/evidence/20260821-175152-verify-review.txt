工单工作台 — AI Vibe Coding 状态机工作流（Layer 2，vibe-workbench 移植）

用法: zcode ticket <command> [args]

  init <project|.>      铺工作台骨架（含 git init + hook + 项目登记；已有项目加 --existing）
  ask [topic]           情境路由：这个情况该用什么（如 zcode ticket ask commit）
  add [title] [依赖] [描述]  新增工单（自动编号；参数可省略，省略则交互提问）
  begin <ticket>        拾取工单 → in-progress, Phase=analyze（依赖守卫 + 自动开分支）
  phase <name> [flags]  推进阶段（守卫校验 + 验证证据留痕）
                         flags: --green 验证绿 | --red 验证红 | --pass 审查过 | --reject 打回 | --force 跳过产物守卫
  transition <t> <s>    流转工单（backlog→in-progress→review→done，blocked→backlog）
  close <ticket>        review→done（校验 Resolution + 已提交 + 自动合并分支），Phase 复位 analyze
  resolve <t> <note>    记录工单修复情况（根因+修复+验证）；close 前必须
  context [ticket]      按需上下文摘要（接手仓库先跑它，省 token）
  gloss [term|list|add]  术语表：列出 / 查询 / zcode ticket gloss add <术语> <定义>
  status                生成 STATUS.md 单屏总览（状态命令会自动刷新）
  validate              全量一致性校验（含依赖环、术语表、STATUS 保鲜）
  next                  建议下一步：可拾取/依赖未满足/进行中
  log                   倒序查看流转历史 (.vibe/log.md)
  install               安装 pre-commit hook 到当前仓库
  projects              列出已登记项目及各自状态
  switch <name>         切到项目目录（bash/zsh 打印路径）
  project-add <path>    登记项目到注册表 (~/.vibe/projects.json)
  check-commit          pre-commit hook 入口（提交前状态机校验）
