## 一、已确认的开发偏好

| 项 | 决策 | 说明 |
|----|------|------|
| 对话与文档语言 | **中文（含思考过程）** | 始终用中文与用户对话，思考内容同样使用中文 |
| 记忆层实现路线 | **先 mem0 后自建** | 先用 mem0 跑通本地记忆闭环（成熟、支持广），同时抽象统一记忆接口，验证后再决定是否自建替换 |

| 目标模型 | **Qwen3.6-35B（本地 llama.cpp 部署，实测）** | 实际部署为 Qwen3.6-35B-heretic-Q5_K_M（35B，原计划 27B 档）；位于 14B-32B 档位附近 |
| 部署框架 | **llama.cpp** | `llama-server` 提供 OpenAI 兼容端点（`/v1`），LLM 走该端点 |
| 上下文窗口 | **256K** | 上下文预算宽裕，技能体积不做硬性限制，但见 2.3 精简建议 |
| Embedding | **未确定（待定）** | 可选：llama.cpp embedding server（GGUF，与 LLM 共用环境）/ Ollama / HuggingFace，选型后填实 profile |
| 优化范围 | 记忆层本地化 + 技能内容精简 + 推理框架适配 | 详见 `docs/本地小模型优化-设计草案.md` |
| 本地默认配置 | **不锁定、可配置** | profile 模板化，除已确定项外默认值占位，部署时按实际硬件填写 |
| 记忆数据位置 | **全局 + 项目分层** | 全局 `~/.zcode/memory`（技能经验，跨项目共享）；项目内 `.memory/`（项目快照） |
| 参考源码 | `mem0/` 仅学习，不提交 git | 已加入 `.gitignore`（规则 `/mem0/`） |
| 技能封装 | Anthropic Agent Skills 标准（`SKILL.md`） | 双版本：`SKILL.md`（云/强模型）、`SKILL.local.md`（本地小模型） |
| 设计哲学 | 小、可组合、随时可改 | 避免过度设计；检索零 LLM，LLM 只用在必须处 |

## 二、默认配置（模板）

### 2.1 本地 profile 模板（对应 `adapters/profiles/local-qwen3.6-35b.yaml`）

```yaml
name: local-qwen3.6-35b
model_family: qwen3.6-27b
context_window: 262144        # 256K
tool_level: <自动探测>          # 0=无工具 1=提示词编码 2=原生 tool calling
json_reliability: <部署时评估>  # low / medium / high
skill_variant: local           # 加载 SKILL.local.md
memory:
  llm:           {provider: openai, base_url: <llama-server 地址>, model: qwen3.6-27b}   # 本地 OpenAI 兼容端点
  embedder:      {provider: <待定>, model: <待定>, dims: <与向量库已有数据一致>}
  vector_store:  {provider: qdrant, path: ~/.zcode/memory}
  infer_mode:    simplified     # 记忆写入用简化提取提示词（四级降级 L0-L3）
  write_frequency: low          # 低频批量回写，省本地算力
```

### 2.2 记忆数据布局

```
~/.zcode/memory/            # 全局：技能经验库（向量库数据 + SQLite 历史，mem0 风格）
<project>/.memory/          # 项目内：context-snapshot.json 等轻量快照（是否入库由项目自定）
```

### 2.3 关键约束（依据 mem0 源码事实）

- 向量库默认 **Qdrant 嵌入式**（BM25 混合检索仅 qdrant / pgvector / milvus / redis 支持；chroma / faiss 会退化为纯语义检索）。
- Embedding 质量 ≥ Qwen 600M 级（`nomic-embed-text` 512 维仅起步档；推荐 `gte-Qwen2-1.5B` 级）。
- 换 embedder 时 `dims` 必须与向量库已有数据一致，否则维度报错。
- **检索零 LLM**（mem0 v3 `search()` 无 query rewrite）；LLM 仅用于记忆写入的事实提取（四级降级：L0 `infer=False` 纯 embedding → L1 简化提示词 → L2 容错解析 → L3 批量合并）。
- 技能注入按需加载：启动只注入技能索引，激活某技能时才读完整 `SKILL.md`。
- 技能文件体积：256K 上下文下**不做硬性 ≤3K 限制**；但 14B-32B 档在超长上下文下指令遵循质量会衰减、kv cache 与延迟上升，**仍建议精简**，具体上限待部署实测后确定。

## 三、待定项（后续问答确认）
