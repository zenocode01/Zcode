# 通用语言词汇表

本文件记录项目的领域术语，消除歧义。当术语有多个含义、命名不清或需要沉淀时，在此补充词条。
词条格式机器可解析（`## 术语` + `- **含义**：` 一行），由 `zcode ticket gloss` 命令管理：
`zcode ticket gloss` 列出、`zcode ticket gloss <术语>` 查询、`zcode ticket gloss add <术语> <定义>` 记录。

### 词条格式

```markdown
## 术语名
- **含义**：一句话定义
- **别名/冲突**：其他叫法或需要澄清的歧义
```
